# Languages

The Example uses the `RunestoneJavaScriptLanguage` product from the root Runestone package. Apps can use the same product from the Runestone Git URL and continue to import `RunestoneJavaScriptLanguage`.

For local development, add the root of the Runestone checkout as the package. The language sources and queries are under `Sources/RunestoneJavaScriptLanguage` at the repository root.
